What was built

A small, auditable workflow — not a black box.

Ingest

Reads the three CSV exports with no manual copy-paste.

Normalize

Applies deterministic parsing rules and keeps raw values for audit.

Validate

Checks referential integrity, duplicates, numeric bounds, and email format.

Package

Writes a styled workbook, clean CSVs, exception log, and KPI JSON.

Validation

Every exception is visible.

The workflow does not hide bad rows. It separates what is safe to report from what needs a human decision.
