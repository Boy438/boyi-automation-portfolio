What was built

A small, auditable extraction workflow.

Read

Scans every PDF and checks whether a text layer exists.

Parse

Uses label-based extraction for header fields and line-item rows.

Check

Reconciles line math, subtotal, tax, total, duplicates, and currency.

Package

Writes clean CSVs, exception log, summaries, and Excel.

Validation

Extraction is only useful if the math checks out.

The workflow does not silently accept a bad invoice. It separates clean rows from the manual-review queue and shows exactly why a file was excluded.
