Workflow

Five steps. One visible decision at each step.

1

Scan

Walk the inbox, capture names, sizes, and SHA-256 hashes.

2

Detect

CSV, JSON, TXT, PDF, or content-sniffed file without an extension.

3

Validate

Check empty files, malformed CSV, corrupt PDF, unsupported types, and duplicates.

4

Plan

Decide organize, skip, ignore, or quarantine with a written reason.

5

Apply safely

Copy only when asked; write the manifest and exception log every run.

Demo limits and disclosure

This is an independent demo on synthetic files. It does not connect to Google Drive, Dropbox, SharePoint, email, or a database. The default command is a dry run; --apply copies files into a separate output folder and never deletes the source. PDF metadata is limited to page count and extractable first-page text. AI-assisted build with human review and testing; the runtime pipeline is deterministic and does not call an external model. Ambiguous dates are parsed as US-style month/day/year in this demo.
