## FAQ

**Do you delete or move my original files?**  
No. The default command is a dry run. The `--apply` step copies approved files into separate output folders and leaves the source untouched. Deletion is not part of the standard package.

**Can you work with Google Drive, Dropbox, or SharePoint?**  
Start by exporting or syncing a sample folder locally. A live cloud connection is a separate scope and must be discussed before ordering.

**Can you handle PDFs without text?**  
The demo reads typed PDFs and flags image-only PDFs for manual review. Full OCR is a separate scope.

**How do you detect duplicates?**  
Byte-identical files are detected with SHA-256. The workflow prefers the cleanest source name and keeps duplicate copies in a review folder.

**Can you rename files to my exact pattern?**  
Yes. Send the naming rule and 5–10 examples. I will document the pattern and test it against the sample.

**Do you use AI?**  
Yes, AI-assisted build with human review and testing. The runtime pipeline is deterministic and does not call an external model. If you require zero AI involvement, tell me before ordering.

**Can you guarantee 100% classification accuracy?**  
No. A file workflow depends on the rules and file types. I use content detection, validation, and an exception queue so uncertain files are visible and reviewable.

**Can you make it recurring?**  
Yes. The same script can be rerun on next month's folder. A recurring runbook or monitoring package can be quoted separately.
