## Gig description

If your invoice PDFs are slowing down bookkeeping, procurement, or reporting, I can turn them into a clean, validated Excel or CSV file.

Send me 1–3 sample PDFs and the exact columns you need. I will confirm fit, scope, and a fixed price before work starts.

**What I can extract**

- Vendor and customer details
- Invoice number and invoice date
- Due date and PO number
- Currency and payment terms
- Line-item description, quantity, unit price, and amount
- Subtotal, tax rate, tax, and total

**What I check**

- Quantity × unit price vs. line amount
- Sum of line items vs. subtotal
- Subtotal + tax vs. total
- Duplicate invoice numbers
- Missing required fields
- Whether the PDF has a text layer

**What you get**

- Clean invoice table
- Line-item table
- Row-level exception log
- Excel workbook with summaries
- Repeatable source script
- README with assumptions and limits
- Short captioned walkthrough

**How I work**

AI-assisted build, human-reviewed and tested. I do not hide bad rows or guess data from image-only PDFs. Every excluded file gets a reason in the exception log.

**Good fit**

- Typed PDF invoices with a text layer
- Bookkeeping, procurement, agency, and operations teams
- Batch extraction into Excel or CSV
- One-off cleanup or a recurring monthly workflow

**Not a fit**

- Handwritten invoices or low-quality phone photos
- Image-only scans that require OCR in the first version
- Projects requiring account credentials or sensitive data without a masking plan
- “100% accuracy” promises without a written field spec

## FAQ

**Do you support scanned PDFs?**  
The demo flags image-only PDFs instead of guessing. OCR can be quoted separately after reviewing a sample.

**What PDF layouts do you support?**  
Typed invoices with label-based fields work best. Send 1–3 samples before ordering so I can confirm the layout.

**Can you extract line items too?**  
Yes. Basic and Standard include line-item extraction. Custom grouping or multi-page tables can be quoted separately.

**What if the math does not match?**  
The file is excluded from the clean output and added to the exception log with the mismatch details.

**Do you use AI?**  
Yes, AI-assisted build with human review and testing. I disclose it up front. If your project requires zero AI involvement, tell me before ordering.

**Do you need my accounting software login?**  
No. Start with a sample PDF export. Account access is not required for the first quote or demo.

**Can you make it recurring?**  
Yes. The same script can be rerun on the next batch. A recurring monthly extraction package can be quoted separately.

**Can you guarantee 100% accuracy?**  
No honest workflow can guarantee that without a written field spec. I use deterministic parsing, validation checks, and an exception log so the output is auditable.
