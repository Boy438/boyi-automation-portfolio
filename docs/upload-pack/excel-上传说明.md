# Excel 旗舰作品：上传说明

> 这是 1 号作品「脏 Excel → 自动周报」的完整证明包。所有数据均为合成数据，页面和文案都已明确标注 **Independent demo — synthetic data**，没有编造客户名、logo 或好评。

## 一、先看哪里

1. 打开 `case-study.html`：这是可以直接给客户看的交互案例页。
2. 打开 `pdf/case-study.pdf`：4 页英文案例，适合放 Contra 作品附件。
3. 看 `video/demo.mp4`：80 秒英文屏幕演示，无配音，有字幕。
4. 看 `images/`：3 张 Fiverr gig 图 + 1 张 Contra 封面。
5. 看 `copy/`：Fiverr 标题/描述/套餐/FAQ、Contra 项目文案、提案模板、上传清单。

## 二、Fiverr 怎么上传

1. 新建 gig，标题用：
   `I will clean messy Excel data and automate your weekly report`
2. 主图上传 `images/gig-01-cover.png`。
3. 另外两张上传 `images/gig-02-before-after.png`、`images/gig-03-workflow.png`。
4. 视频上传 `video/demo.mp4`。
5. 描述直接复制 `copy/fiverr-gig.md` 里的 **Gig description**。
6. 套餐按文案设置：**$45 / $120 / $280**，交付 **2 / 3 / 5 天**，修改 **1 / 2 / 3 次**。
7. 标签：`excel`、`data cleaning`、`spreadsheet`、`automation`、`google sheets`。
8. 在 Portfolio 区域放 `pdf/case-study.pdf`、`copy/orders_clean.csv`、`copy/exceptions.csv`、`copy/cleaned_weekly_report.xlsx`。
9. 不要在 gig 描述里放站外联系方式、收款方式或导流链接。Fiverr 站内只放图片、视频、样例文件。

## 三、Contra 怎么上传

1. 新建 Project，标题用：
   `Messy Spreadsheets → One-Click Weekly Report`
2. 封面用 `images/contra-cover.png`。
3. 项目描述复制 `copy/contra-project.md`。
4. 附上 `case-study.html` 的在线链接（GitHub Pages 开通后）。
5. 附上 GitHub 仓库链接和样例输出文件。
6. 明确写：`Independent demo — synthetic data`。
7. 再建一个 Service：
   `Excel / CSV Cleanup & Reporting Automation — from $120`
8. 每天投 3 个定制提案，模板在 `copy/contra-project.md` 的 **Proposal template**。
9. 提案里不要群发，必须引用对方的具体需求，并给出一个相关作品链接。

## 四、GitHub Pages 怎么开

1. 在 GitHub 新建仓库，把 `D:\FreelanceWorkbench\03_projects\spreadsheet-report-automation` 推上去。
2. 仓库 Settings → Pages → Source 选 `Deploy from a branch`。
3. Branch 选 `main`，Folder 选 `/docs`。
4. 保存后等 1–2 分钟，访问：
   `https://<你的用户名>.github.io/<仓库名>/`
5. 检查三件事：
   - 页面能打开；
   - Run demo 按钮有效；
   - 三个下载按钮有效。
6. 把这个链接放到 Contra 项目页和 profile。

## 五、第一单策略

- 前 3 单不要打价格战，Basic 保持 $45，保证是完整小结果，不是残缺试用。
- 交付时多送一个格式（例如 CSV + XLSX），但**不要和好评绑定**。
- 交付后只做一次礼貌评价请求，不用折扣/赠品换评价。
- 第 3 个真实评价后，统一涨价 25%–30%。
- 任何需要账号密码、敏感数据、手写扫描件的单子，先拒绝或要求脱敏样例。

## 六、不要做的事

- 不要写“100% accuracy”“unlimited revisions”。
- 不要用假客户 logo、假评价、假“节省 20 小时/周”案例。
- 不要接违反网站条款的抓取单。
- 不要在 Fiverr 描述里放站外链接或收款方式。
- 不要把 demo 说成真实客户项目。就写 Independent demo，反而更可信。
