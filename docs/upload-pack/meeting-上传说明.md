# 会议录音 → 纪要 / 行动项 / SRT：上传说明

> 这是 3 号作品「会议录音 → 纪要 + 行动项 + 双语字幕」的完整证明包。音频和转写均为合成数据，页面和文案都标注 **Independent demo — synthetic audio**，没有编造客户名、logo 或好评。

## 一、先看哪里

1. `case-study.html`：交互案例页，带音频播放器和转写/行动项对比。
2. `pdf/case-study.pdf`：4 页英文案例。
3. `video/demo.mp4`：80 秒英文演示，无配音、有字幕。
4. `images/`：3 张 Fiverr 图 + 1 张 Contra 封面。
5. `copy/`：Fiverr/Contra 文案、提案模板、上传清单、样例音频、笔记和 SRT。

## 二、Fiverr 怎么上传

1. 新建 gig，标题：
   `I will turn meeting recordings into clear notes, action items, and subtitles`
2. 主图：`images/gig-01-cover.png`
3. 第 2 张：`images/gig-02-before-after.png`
4. 第 3 张：`images/gig-03-workflow.png`
5. 视频：`video/demo.mp4`
6. 描述复制 `copy/fiverr-gig.md` 的 **Gig description**。
7. 套餐：**$45 / $95 / $180**；交付 **1 / 2 / 3 天**；修改 **1 / 2 / 3 次**。
8. 标签：`meeting notes`、`transcription`、`subtitles`、`action items`、`srt`。
9. Portfolio 放 `pdf/case-study.pdf`、`copy/action_items.csv`、`copy/notes/`、`copy/srt/`、`copy/audio/`、`copy/meeting_notes_report.xlsx`。
10. Fiverr 描述里不要放站外联系方式、收款方式或导流链接。

## 三、Contra 怎么上传

1. 新建 Project，标题：
   `Meeting Audio → Notes, Actions & Bilingual SRT`
2. 封面：`images/contra-cover.png`
3. 项目描述复制 `copy/contra-project.md`。
4. 附上 `case-study.html` 的在线链接（GitHub Pages 开通后）。
5. 附上 GitHub 仓库、样例 MP3、笔记、SRT 和 Excel。
6. 明确写：`Independent demo — synthetic audio`。
7. 新建 Service：
   `Meeting Notes + Action Items — from $95`
8. 每天投 3 个定制提案，模板在 `copy/contra-project.md` 的 **Proposal template**。
9. 提案必须引用对方的具体需求，并附一个相关作品链接。

## 四、GitHub Pages 怎么开

1. 在 GitHub 新建仓库，把 `D:\FreelanceWorkbench\03_projects\meeting-notes-flagship` 推上去。
2. Settings → Pages → Source 选 `Deploy from a branch`。
3. Branch 选 `main`，Folder 选 `/docs`。
4. 等 1–2 分钟，访问：
   `https://<你的用户名>.github.io/<仓库名>/`
5. 检查页面、音频播放器、Run pipeline 按钮和三个下载按钮是否正常。
6. 把链接放到 Contra 项目页和 profile。

## 五、第一单策略

- 前 3 单不要打价格战，Basic 保持 $45，保证是完整小结果。
- 先让客户发 1 个 1–3 分钟的样例音频，确认音质和口音。
- 明确写：原始 ASR 会有错误，最终笔记使用人工校正后的转写。
- 遇到多人重叠说话、强噪声、法律/医疗/金融正式转写，先说明限制或拒绝。
- 交付时多送一个 SRT 变体，但**不要和好评绑定**。
- 交付后只做一次礼貌评价请求，不用折扣/赠品换评价。
- 第 3 个真实评价后，统一涨价 25%–30%。

## 六、不要做的事

- 不要承诺“100% accuracy”。
- 不要把 raw ASR 直接当最终交付。
- 不要编客户案例、假 logo、假评价。
- 不要在 Fiverr 描述里放站外链接或收款方式。
- 不要把 demo 说成真实客户项目。写 Independent demo 反而更可信。
