# First 3 Orders Playbook

## Order intake

Ask four questions before quoting:

1. Can you send one representative sample?
2. What exact output do you need?
3. What rules should I follow for dates, duplicates, currency, names, or languages?
4. What is your deadline?

## Quote template

Hi — thanks for the sample. I can deliver [output] for [price] within [time]. The scope includes [3 bullets]. I will validate [key risk] before delivery. Revisions: [number]. If that works, I can start after the order is placed.

## Delivery SOP

1. Write a one-page brief with assumptions and exclusions.
2. Run the workflow on the real sample, not just the demo data.
3. Check 10% of the output manually; check all low-confidence/exception rows.
4. Package:
   - clean output
   - exception log
   - README / run instructions
   - short walkthrough
5. Deliver through the platform only.
6. Archive the delivery and reusable parts.

## Review request

After acceptance:

> Thanks for the order. If the delivery was useful, an honest review helps me build the new profile. No pressure — I’m glad the output is working for you.

Do not attach discounts, gifts, or refunds to the review.

## Raise plan

- First 3 orders: launch price.
- After 3 real reviews: +25%–30%.
- After 10 reviews: review scope and add a recurring package.
- Never compete on being the cheapest.
