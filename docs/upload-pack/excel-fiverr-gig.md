## FAQ

**Can you work with Google Sheets?**  
Yes. Export the sheet as XLSX or CSV and send a sample. If the project needs a live Google Sheets connection, describe it first so I can confirm scope.

**What if my files have different column names?**  
That is normal. I map your columns to the required output schema and document the mapping.

**What happens to invalid rows?**  
They are excluded from the clean output and written to an exception log with the row number, field, issue, and action taken.

**Do you use AI?**  
Yes, AI-assisted build with human review and testing. I disclose it up front. If your project requires zero AI involvement, tell me before ordering.

**Will the result run on my computer?**  
Yes, for Standard and Premium you receive the source script, dependency list, and run instructions. I test the workflow end to end on the sample data.

**Can you guarantee 100% accuracy?**  
No honest workflow can guarantee that without defining the data rules. I use validation checks, exception flags, and a sample-first process so the output is auditable.

**Do you need my account passwords?**  
No. Start with exported sample files. Account access is not required for the first quote or demo.

**Can you make it recurring?**  
Yes. The same script can be rerun on next week's exports. A recurring monitoring/reporting package can be quoted separately.
